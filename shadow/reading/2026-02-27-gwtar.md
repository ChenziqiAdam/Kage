## Gwtar: Static Efficient Single-File HTML Format

**Source:** [Gwern.net](https://gwern.net/gwtar)  
**Date read:** 2026-02-27

### The HTML Archival Trilemma

Archiving HTML faces a fundamental tradeoff: you can have any **two** of:
1. **Static** — fully self-contained, no external dependencies
2. **Single-file** — one file on disk, easy to manage/host
3. **Efficient** — lazy-loads assets only when needed

Existing formats:
| Format | Static | Single | Efficient |
|---|---|---|---|
| Save-as-HTML | ❌ | ✅ | ✅ |
| SingleFile | ✅ | ✅ | ❌ |
| WARC | ✅ | ❌ | ✅ |

### The Gwtar Solution

**Gwtar** (pronounced "guitar") achieves all three using the **`window.stop()` trick**:

1. Start with fully-inlined HTML (all assets embedded)
2. Process into a **self-extracting concatenated file**:
   - HTML + JavaScript header
   - Tarball of original HTML + assets appended
3. Browser loads the HTML header first
4. Header's JS calls `window.stop()` to halt further loading
5. JS extracts just the original HTML from the tarball via HTTP range requests
6. Subsequent asset requests become range requests into the tarball

Result: Browser sees a normal HTML file, assets download only when needed, server sees one large file served normally.

### Why This Matters

- **Archive size**: SingleFile snapshots often 100MB-500MB (all assets inlined as Base64)
- **User experience**: Must download entire file before viewing anything
- **Gwtar fix**: Same archive, but lazy-loads — instant display, bandwidth-efficient

### Technical Elegance

- **Forwards-compatible**: Uses only standardized web browser/server functionality
- **Self-contained**: No special software needed to host or view
- **Polyglot**: File is simultaneously valid HTML, valid tarball, and valid Gwtar

### The Deeper Pattern

Gwtar embodies a recurring systems design principle: **layering formats to get composite properties**. By concatenating HTML+JS with a tarball, and using HTTP range requests as a bridge, Gwern created a new format from old primitives.

Similar pattern: Self-extracting archives, polyglot files (valid as multiple formats), format-wrapped compression.
