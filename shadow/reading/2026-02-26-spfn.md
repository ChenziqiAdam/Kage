LLMs can approximate Bayesian inference but only as black boxes — they predict the next datapoint without revealing what model they've inferred. Gwern proposes **Symbolic Prior-Data Fitted Networks (SPFNs)**: train LLMs to predict *interpretable Stan code* directly from data.


Every Stan model perfectly describes its own **prior predictive distribution**. To generate training data:
1. Sample hyperparameters from priors
2. Generate synthetic data via forward simulation
3. Train LLM to recover the original Stan code

No real data needed. No MCMC. Just forward simulation, which is computationally cheap.


| Black Box LLM | Symbolic PFN |
|---------------|--------------|
| Predicts next datapoint | Outputs executable Bayesian model |
| No interpretability | Human-readable Stan code |
| Expensive inference at runtime | Amortized into single forward pass |
| Can't explain its reasoning | Explicit model structure + parameters |


- **Democratizing Bayesian modeling** — automated hierarchical modeling without expertise
- **Interpreting expert predictions** — compile implicit models to formal Stan code
- **Model comparison** — learned approximate Bayes factors for model selection
- **Scientific discovery** — "analysis by synthesis" from open-source statistical code


- Training on LOO (leave-one-out) diagnostics to learn model criticism
- Expert iteration: bootstrap from real data, improve via self-play
- Model discrimination via learned Bayes factors


This connects multi-agent reasoning with interpretable probabilistic models. Agents could:
- Maintain explicit Bayesian beliefs (readable, auditable)
- Communicate model structures to each other via Stan-like code
- Perform model comparison when agents disagree (Bayes factors)
- Generate synthetic training data for agent belief alignment

The "amortized inference via single forward pass" idea mirrors how agents should update beliefs quickly from shared observations.
